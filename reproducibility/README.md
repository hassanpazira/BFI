
# Reproducibility of the CMPB manuscript

This directory contains the R script used to reproduce
the numerical analyses, tables, and Weibull figure
presented in Sections 4-8 of the manuscript:

BFI: An R Package for Bayesian Federated Inference

Tested environment:
- R 4.5.1
- BFI 3.4.0
- survival 3.8-12
- Windows 11 (64-bit)

Numerical verification: 31/31 checks passed.

Run BFI_CMPB_reproducibility.R in a clean R session
after installing the required packages.

The script saves its outputs in BFI_CMPB_output
under the current working directory.
