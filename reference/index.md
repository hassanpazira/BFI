# Package index

## Main functions

- [`MAP.estimation()`](https://hassanpazira.github.io/BFI/reference/MAP.estimation.md)
  : Maximum a posteriori estimation
- [`bfi()`](https://hassanpazira.github.io/BFI/reference/BFI.md) :
  Bayesian Federated Inference
- [`inv.prior.cov()`](https://hassanpazira.github.io/BFI/reference/inv.prior.cov.md)
  : Creates an inverse covariance matrix for a Gaussian prior
- [`summary(`*`<bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/summary.bfi.md)
  [`print(`*`<summary.bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/summary.bfi.md)
  : Summarizing BFI fits
- [`hazards.fun()`](https://hassanpazira.github.io/BFI/reference/hazards.fun.md)
  : Compute the estimated (baseline/cumulative) hazard and (baseline)
  survival functions
- [`coef(`*`<bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/bfi-methods.md)
  [`print(`*`<bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/bfi-methods.md)
  [`vcov(`*`<bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/bfi-methods.md)
  : Methods for local and federated BFI objects
- [`confint(`*`<bfi>`*`)`](https://hassanpazira.github.io/BFI/reference/confint.bfi.md)
  : Approximate posterior credible intervals for BFI models

## Supporting functions

- [`surv.simulate()`](https://hassanpazira.github.io/BFI/reference/surv.simulate.md)
  : Generate survival data with predefined censoring rates for
  proportional hazards models
- [`b.diag()`](https://hassanpazira.github.io/BFI/reference/b.diag.md) :
  Create a block diagonal matrix
- [`n.par()`](https://hassanpazira.github.io/BFI/reference/n.par.md) :
  Number of predictors, coefficients, and observations

## Data sets

- [`Nurses`](https://hassanpazira.github.io/BFI/reference/Nurses.md) :
  Nurses' stress in different hospitals
- [`trauma`](https://hassanpazira.github.io/BFI/reference/trauma.md) :
  Trauma patients from different hospitals

- [`BFI-package`](https://hassanpazira.github.io/BFI/reference/BFI-package.md)
